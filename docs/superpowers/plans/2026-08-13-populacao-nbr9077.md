# População NBR 9077 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Calcular a população exata de depósitos conforme a NBR 9077:2025, integrar o resultado opcionalmente ao vertical de incêndio e bloquear rotas enquanto a política de arredondamento não for decidida.

**Architecture:** Um módulo puro recebe áreas explicitamente classificadas pelo chamador e calcula a área computável e a população exata. O orquestrador de incêndio apenas repassa o bloco opcional `spec["populacao"]`; a descoberta do loop amarra a unidade a uma única fonte NBR 9077:2025 e a um teste focal.

**Tech Stack:** Python 3.12, `math`, `numbers.Real`, `pytest`, NotebookLM via `nlm`, máquina de estados em `tools/loops`.

## Global Constraints

- Usar somente o NotebookLM `09_INCENDIO` e o source ID `878dc921-2664-43ec-b2c8-14641b3c7641` para esta unidade.
- Aplicar 30 m² por pessoa somente ao caso “Depósitos em geral” da Tabela 4.
- A NBR 9077:2025 não declarou critério de arredondamento nesta pesquisa; não escolher uma política implicitamente.
- Não deduzir área computável automaticamente de `geometria.L * geometria.W`.
- Não alterar caminhamento, largura, número de saídas, BIM ou pranchas nesta fase.
- Toda alteração de produção terá teste RED observado antes do GREEN.
